# Data directory

The FoG-STAR dataset is not redistributed in this repository.

Download the public dataset from Zenodo (DOI: `10.5281/zenodo.17838806`) and create:

```text
data/
└── raw/
    ├── sensor_data.csv
    └── clinical_data.csv
```

All processed files are generated locally by the included analysis scripts and are excluded from version control.
